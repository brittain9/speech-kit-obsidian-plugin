Recording handling also preserves completed audio when transcription stops with an error or backlog. If the note cannot accept the player, the audio stays saved and a notice shows its link. ## How to smoke test

Use **test-vault** and a new scratch note. The version number stays unchanged because this is a maintenance installation, not a release.

| Test                   | Steps                                                                                                                                                                                                       | Expected result                                                                                                                                                                                   |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Speak, type, and paste | Use a streaming model. Start dictation. While a phrase is changing, type a few words and paste a URL at its end. Continue speaking, then stop.                                                              | The typed text and URL remain. New speech follows them when the final transcript retains the visible phrase. Edits inside speech stay protected.                                                  |
| Save audio             | Enable **Settings → Speech Kit → Save microphone recording**. Dictate and stop. Play and seek in the resulting audio player.                                                                                | The file uses Obsidian's configured attachment location. The player appears beside the transcript. The saved recording contains microphone audio only.                                            |
| Cancel audio           | Start another session, then run **Speech Kit: Cancel dictation**.                                                                                                                                           | The session returns to idle without adding another player or active recording file.                                                                                                               |
| Provider setup         | Enable **LLM features**. Select **Open sidebar**, then close Settings. Choose Ollama and an installed chat model. Leave **Transform dictation** off.                                                        | Provider controls remain available. If Ollama is stopped, the sidebar explains that it is unavailable. File and YouTube dialogs can use a chosen AI preset independently of dictation transforms. |
| Translate              | Translate a short English note to Spanish with an installed model. Swap directions, then swap back or retry. Select **Insert below**.                                                                       | A changed direction marks the old preview stale. Insert below preserves the source and adds the translation.                                                                                      |
| Discover languages     | In **Manage models**, select German under Speech to text. Switch to Translation and select Filipino.                                                                                                        | German speech models are visible. Filipino shows compatible HY-MT translation models and explains the lack of compatible speech models. Filters stay separate for each task.                      |
| German transcription   | Run **Transcribe local audio file**. Choose `native/tests/fixtures/audio/de-fleurs-1577.wav` from this repository. Select **Deutsch** and installed **Whisper Large V3 Turbo**. Choose **Transcript only**. | A German transcript is inserted locally. German does not require a new model integration.                                                                                                         |
| Read aloud             | Run **Read aloud from selection or note start**. If needed, follow **Choose model** and select an installed English voice model.                                                                            | Local reading starts and finishes. Pause and stop controls remain available during playback.                                                                                                      |
| Setup                  | In Speech Kit settings, run setup. Check the microphone and continue to the ready step.                                                                                                                     | The check releases the microphone. The ready step explains the ribbon and hotkey and does not start dictation until requested.                                                                    |

## QA evidence and limits

Native QA used Obsidian 1.15.0 on macOS and the test vault. It covered English file transcription, German Whisper transcription, HY-MT English-to-Spanish translation, direction swapping, language discovery, microphone readiness, provider navigation, Pocket TTS reading, live typing and URL pasting with replayed speech, recording playback and seeking, recording cancellation, and invalid-audio rejection without changing the note. The final smoke test also preserved both existing paragraphs around a dictated passage and recording embed.

The final combined frontend gate passed **1,760 tests**, with 10 skipped. Real CodeMirror editor tests cover nested edits, manual-edit protection, overlapping sessions, disposal, recording placement, and cleanup recovery.

Automated checks include TypeScript and Obsidian-floor compatibility, Biome, Obsidian ESLint, tests, and the production frontend build. The Rustls patch passed local Rust formatting, all-engine Clippy with warnings denied, and Rust tests. GitHub dependency and code-scanning alerts were both zero after the security patches.

Two native safety stops were observed early in QA. The exact trigger was not established. The nested-update defect was separately reproduced in a real editor and fixed in #501; later native smoke tests passed.

Ollama was not running during this initial pass, so it checked provider discovery and the unavailable state. Later controlled-provider checks are in the LLM settings record above. Native Windows, Linux, mobile, and screen-reader testing are separate from this Mac QA. Short fixture checks establish that the workflows operate; they are not a broad model-accuracy benchmark.

The German model linked in the [#418 comment](https://github.com/brittain9/speech-kit-obsidian-plugin/issues/418#issuecomment-6607692242) contains Transformers/safetensors files. Speech Kit's external Whisper importer expects a whisper.cpp-compatible model. Conversion of that particular model remains unverified. The catalog already offers German transcription through multilingual Whisper Large V3 Turbo and Nemotron ASR.

Issue #476 and correction-rules PR #459 were left untouched. This initial pass did not merge PR #451. Its later workflow-status port is tracked in [#524](https://github.com/brittain9/speech-kit-obsidian-plugin/pull/524).
