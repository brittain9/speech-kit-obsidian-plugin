# Next release briefing — working draft

Release `2026.11.1` is authorized and in preparation. The validated source candidate is `3881d47`; release metadata and final CI remain pending.

## What changed

- **Dictation and recordings:** Typing or pasting a link during live speech is safer, and consecutive sessions keep their intended order. Delayed startup or cancellation cannot take over a newer session. Optional microphone recording saves an Obsidian attachment; it is off by default and excludes system audio. Stop preserves completed audio; Cancel discards an unfinished recording. Temporary note pinning is optional and protects the target tab. [#499](https://github.com/brittain9/speech-kit-obsidian-plugin/pull/499), [#510](https://github.com/brittain9/speech-kit-obsidian-plugin/pull/510), [#521](https://github.com/brittain9/speech-kit-obsidian-plugin/pull/521), [#527](https://github.com/brittain9/speech-kit-obsidian-plugin/pull/527).
- **Translation and reading:** Language discovery and direction swapping are clearer. Cancelled translation cannot start late. Reviewed translation text remains tied to its source note, even across view changes and rename. Reading and translation release their resources safely. [#452](https://github.com/brittain9/speech-kit-obsidian-plugin/pull/452), [#512](https://github.com/brittain9/speech-kit-obsidian-plugin/pull/512), [#515](https://github.com/brittain9/speech-kit-obsidian-plugin/pull/515), [#516](https://github.com/brittain9/speech-kit-obsidian-plugin/pull/516).
- **Models:** Reinstall works with the only selected speech model and preserves it if the update fails or is cancelled. Store changes require Apply and no longer show readiness from a different folder. Corrected Moonshine Tiny files are available; existing installations are not replaced automatically. [#511](https://github.com/brittain9/speech-kit-obsidian-plugin/pull/511), [#517](https://github.com/brittain9/speech-kit-obsidian-plugin/pull/517), [#518](https://github.com/brittain9/speech-kit-obsidian-plugin/pull/518).
- **More speech choices:** Added Parakeet Unified English 1,120 ms, an English Nemotron 560 ms ONNX export, and Nemotron 3.5 multilingual 160 ms. The existing Nemotron 3.5 560 ms files remain unchanged. These models run on CPU; actual delay depends on the computer and workload. [#520](https://github.com/brittain9/speech-kit-obsidian-plugin/pull/520), [#522](https://github.com/brittain9/speech-kit-obsidian-plugin/pull/522).
- **Settings, status, and recovery:** Provider, model, API key, and preset controls are easier to find in Settings. File and YouTube dialogs have clearer spacing. The model picker groups searchable results by family. Status shows when speech is still processing; incomplete transcripts can be reopened, copied, or inserted safely. [#523](https://github.com/brittain9/speech-kit-obsidian-plugin/pull/523), [#524](https://github.com/brittain9/speech-kit-obsidian-plugin/pull/524), [#532](https://github.com/brittain9/speech-kit-obsidian-plugin/pull/532), [#533](https://github.com/brittain9/speech-kit-obsidian-plugin/pull/533).
- **Security and documentation:** Dependency and TLS advisories were patched, contributor tools were aligned, CI builds use portable CPU defaults, and user and technical guides were refreshed. The Node requirement applies to contributors, not plugin users. [#503](https://github.com/brittain9/speech-kit-obsidian-plugin/pull/503), [#507](https://github.com/brittain9/speech-kit-obsidian-plugin/pull/507), [#528](https://github.com/brittain9/speech-kit-obsidian-plugin/pull/528), [#529](https://github.com/brittain9/speech-kit-obsidian-plugin/pull/529).

## What was verified

Native macOS checks covered the new speech options, a 347-second Tiny dictation session with typing and paste, recording and consecutive sessions, translation source safety, reading, model reinstall and store switching, provider setup, partial recovery, and narrow and standard layouts. These bounded checks are not an accuracy or battery benchmark. Windows and Linux CI built and tested the code; interactive application checks were on macOS. Mobile Obsidian is not supported.

The English NVIDIA conversions are pinned, but their exact source checkpoints are not proven. The English Nemotron export is not labeled as a verified v2603 conversion. Detailed provenance, tests, and limits are in the [model research](../research/2026-11-nvidia-asr-options.md) and [validation record](2026-11-extended-validation.md).
