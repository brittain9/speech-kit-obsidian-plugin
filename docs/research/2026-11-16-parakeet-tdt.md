## Outcome: reject this export for managed recommendation

The complete 670,719,803-byte candidate was downloaded once. Actual SHA-256 values matched the three LFS metadata hashes. The small companions hash to `d58544679ea4bc6ac563d1f545eb7d474bd6cfa467f0a6e2c1dc1c7d37e3c35d` (vocab.txt) and `666903c76b9798caf2c210afd4f6cd60b08a8dbf9800ec8d7a3bc0d2148ac466` (config.json). Model-work transfers now total 1,212,377,861 bytes, including prior repeated installer transfers; unique model artifacts total 925,341,362 bytes. Small public audio/API/source downloads are additional, below the 2 GB overall budget. No further model weights were requested.

A real Rust adapter now exists only on the isolated experimental branch. It validates all graph names/types/shapes, uses int32 decoder targets, separates the prediction-length output, resets recurrent state per request, and bounds zero-duration emissions. Registry and short German recognition tests were written failing before implementation. A decoder tie-breaking regression also caught Rust's last-index maximum differing from NumPy's first-index maximum; the adapter now matches the reference.

The eight existing supported product-language short clips passed the established floors (English WER 3.8%, Dutch 11.1%, others 0%), including Croatian and German automatic transcription. However, natural German recordings failed: direct WER 40.7% on 26.58 seconds and 92.3% on 23.1 seconds. The output mixed English with German and omitted substantial speech. Actual AppState/VAD/worker sessions also failed, at 88.9% and 96.2%; each emitted one final without session errors. The tests retain the original 45% long-fixture floor and intentionally fail when these diagnostic cases are requested.

An independent NumPy/ONNX Runtime greedy decoder reproduced all three German raw outputs exactly, using the same pinned encoder, joint decoder, and feature graph. Runtime versions were ONNX Runtime 1.24.4 and NumPy 2.4.4; no new Python packages were installed. Reviewed preprocessing source agrees on the NeMo per-feature normalization, 128 bands, 10 ms hop, and 8x encoder subsampling. This supports a candidate-export/model limitation rather than claiming the Rust decoder introduced the observed words. It does not prove all upstream float/other exports share the problem.

The observed short-fixture inference speed is not sufficient reason to adopt a model that loses natural speech. No shipping catalog entry, default, TypeScript family option, build-script feature, or release was changed. Do not count this experiment as a delivered recommended model. Further candidates need fresh evidence rather than a weaker threshold. See the [quality record](../quality/2026-11-16-parakeet-tdt-experiment.md).
