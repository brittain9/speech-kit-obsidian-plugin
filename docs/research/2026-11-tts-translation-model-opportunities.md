# TTS and translation model opportunities

Reviewed 2026-11-08 against `origin/main` at `db75b7e84104b7bc9f2a29f76d694a5e3789653d`.

## Recommendation

The October 2026 Pocket TTS update is the most promising quality investigation. It addresses sentence-final number handling and adds a Dutch model. However, the ONNX export is unofficial, upstream gated terms apply, and its file names and some precision choices differ from the plugin's current Pocket adapter contract. Do not download through an unofficial mirror or accept new access terms for this investigation. First confirm a permitted official access/export path; then compare one exact pinned export against the current adapter using the existing test process. Until then this is a proposal, not an integration candidate.

Second, test Tencent HY-MT 2's Q6_K quantization as an optional quality tradeoff. The artifact is GGUF and the existing translation path uses llama.cpp. It adds no new model family or languages. Keep the current Q4_K_M default unless a bounded comparison shows useful quality improvement for an acceptable increase in storage, memory, and latency.

Third, evaluate one additional Supertonic 3 language using the already-installed model. The upstream model card lists 31 languages, while this plugin exposes nine that have passed a listening review. A successful review could expand coverage without another model download.

No model was downloaded and no inference or quality comparison was run for this research.

## Bounded next checks

1. For Pocket TTS, first confirm an official, permitted access and export path. Do not access gated weights through an unofficial mirror or accept new access terms. Do not change the catalog until the current maintainer reviews the source and terms.
2. If that gate is resolved, compare current English with one pinned `english_2026-10` export for sentence-final numbers, regular prose, names, punctuation, first-audio latency, total synthesis time, and peak memory. Check the current adapter's exact file, bundle-schema, tensor-name, and dtype contract before inference. Stop if the official access or reproducible export cannot be established.
3. Compare HY-MT 2 Q4_K_M and Q6_K only on a small representative set: English↔Spanish/German, Japanese↔English, Filipino↔English, and two formatted passages. Record exact llama.cpp build, hardware, quality rubric, latency, and peak memory. Stop if the quality difference is not useful.
4. For Supertonic 3, test one upstream-listed language with a blinded listening sample and already-installed model files. Expose it only if pronunciation and intelligibility meet the same review standard as current nine languages.
