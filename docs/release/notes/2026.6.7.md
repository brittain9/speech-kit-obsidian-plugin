## Highlights

- **LLM cleanup now runs locally _or_ in the cloud, with automatic routing.** The transform provider is no longer a single fixed backend. A new **Local / Remote / Auto** control decides where each transcript is cleaned up: **Local** keeps everything on-device with Ollama, **Remote** sends each transcript to OpenRouter, and **Auto** stays on-device for short transcripts and hands only the large ones — which overflow or crawl on a local model — to OpenRouter. The size cutoff for Auto is configurable (character threshold, shown with an approximate token count).
- **Searchable OpenRouter model picker with price tiers.** When a remote model is in play, the picker type-ahead searches OpenRouter's catalog by id or name, filters it down to text-in / text-out chat models (TTS and image-generation models are hidden), and tags each model with a restaurant-style price tier (Free / `$`–`$$$$`) derived from its live prompt+completion pricing so cost is visible before you pick.
- **Remote kill switch.** A single Advanced toggle disables all remote LLM features mid-session: with it off, Auto and Remote both fall back to local Ollama and no transcript leaves the device, regardless of the saved routing mode.
- **Reorganized LLM transformation panel.** The sidebar's transform settings are now sorted into labeled groups — **Where it runs** (routing + provider config), **Style** (preset, mode, and the prompt editor, promoted up out of Advanced), and **Context** (use-note-as-context and its character cap, now together). Advanced is slimmed from five sub-cards to three (Limits / Generation / Diagnostics). Turning Transform off now shows a one-line explainer instead of a bare, empty toggle. No settings or behavior changed — only where each control lives.

## Fixes

- **Long transforms are no longer truncated.** The output-token cap was a fixed 4,096 on both the local and remote paths, so cleaning up a long transcript (or a verbose rewrite) was cut off mid-sentence. The cap now scales with the input — roughly the input length plus headroom — with a floor generous enough that a short "expand this into a paragraph" command isn't clipped, and a ceiling that still guards against runaway cost. Both providers clamp this down to the model's real maximum, and a genuine overflow now surfaces a clear cleanup failure (keeping your raw text) instead of silently dropping the tail.
- **Batch cleanup survives a mid-session edit.** Editing an utterance while a session is still open no longer breaks the end-of-session batch rewrite, and the rewrite no longer overwrites text you changed by hand. Pending per-utterance work is drained before the batch read so the two can't race.
- **OpenRouter picker polish.** Alias entries (`~author/model-latest`) that point at a family's newest model but expose no servable endpoints — and 404 when used — are filtered out of the picker. Typing in the model field no longer loses focus when its inline status line refreshes.

## Internal

- Providers are unified behind one `LlmProvider` interface (Ollama + OpenRouter) with a small size-based router; the legacy Gemini provider and the Rust-side `llm_postprocess` stage were removed. Settings migrate persisted legacy keys (`llmProvider` → `llmRouting`, `llmPostprocessModel` → per-provider model map) on load.
- DRY pass on the provider layer: the per-provider model map is now keyed off the canonical provider-id union, transport budgets (timeouts, response-size cap) are single-sourced, and the input-scaled output budget is shared by both providers. Test suite trimmed to current behavior, with new coverage for size-based routing, the output-token budget, and provider truncation/error mapping.
