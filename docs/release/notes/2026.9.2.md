## Highlights

- **Choose the translation tone.** HY-MT2 translations now offer Standard, Formal, and Casual styles so you can set the register that fits the note.
- **Add your own style guidance.** Custom style instructions provide a free-form field, capped at 500 characters, for preferences such as regional wording or a specific audience.
- **Review before applying.** Style changes are saved for subsequent translation jobs, and the preview makes you retry when a completed result was produced with an older style.

## Compatibility

- Style controls apply to HY-MT2 translations only. Existing translation settings remain valid and default to Standard.
