## Highlights

- **Useful AI presets, ready to customize.** Speech Kit now starts with 16 presets, including Summary, TLDR, Key takeaways, Explain simply, Outline, YouTube notes, Podcast show notes, Study notes, Meeting notes, Explain with analogies, and Comedy recap. Each processes the complete transcript when dictation stops or media import finishes.
- **Your presets belong to you.** Edit, duplicate, or delete any starting preset. Restore transform defaults brings back the shipped prompts and deleted starting presets while keeping presets you created. Markdown formatting remains available; Clean up, Professional writing, Action items, and Voice commands are excluded from the starting set.

## Improvements

- **Keep using Obsidian while processing continues.** Close a YouTube or file transcription dialog to let the job continue in the background, including its AI step. Reopen the command to see progress; use the explicit cancellation control to stop the job.
- **Understand AI failures without opening the console.** Media processing reports specific problems such as rejected API keys, connection failures, unavailable models, or output limits, with a useful next step. The raw transcript stays in your note when AI cannot finish.

## Fixes

- **Import the same YouTube video again.** A previous completed job no longer makes a fresh import show Done without inserting a transcript. Reopening an active job still prevents duplicate insertion.

## Compatibility

- **No native engine update required.** This plugin-only release reuses the compatible 2026.9.3 native engine. Existing custom presets are preserved, and old starting-preset selections migrate to editable saved presets.
