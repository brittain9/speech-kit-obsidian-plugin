## Highlights

- **Record your microphone with dictation.** Optional recording is off by default and saves microphone audio only. Stopping normally adds a player; Cancel discards an unfinished recording.
- **More live speech choices.** Added Parakeet Unified English 1,120 ms, an English Nemotron 560 ms ONNX export, and Nemotron 3.5 multilingual 160 ms. These run on CPU; existing Nemotron 3.5 560 ms files are unchanged.
- **Clearer model and AI settings.** Compact model summaries show availability. Manage models groups searchable results by family. Provider, API key, model, and preset controls are in Settings; daily transform controls remain in the sidebar.

## Improvements

- **Keep writing while you dictate.** Live speech updates protect typed text and pasted links. Consecutive sessions keep their order and respect a deliberate selection.
- **Reinstall and switch stores safely.** Reinstall preserves the selected model if replacement fails or is cancelled. Applying a different model store refreshes availability.
- **See progress and recover partial text.** Status shows when captured speech is still processing. Reopen, copy, or safely insert an incomplete file transcript.
- **Keep translations tied to their source.** Reviewed text stays tied to its source note across view changes and rename. Cancellation prevents a delayed translation from starting.

## Compatibility

- **Updated speech engine.** Update the plugin and its new native engine together.
- **Model downloads and terms.** Corrected Moonshine Tiny files do not replace existing installs automatically. NVIDIA models have separate license terms. The English ONNX exports are pinned, but their exact source checkpoints are unverified; the Nemotron export is not labeled as a verified v2603 conversion.
- **Security updates.** Updated dependencies and TLS roots address known advisories. Shared native builds use portable CPU defaults.
