## Highlights

- **Transcribe audio and video files.** Drop or browse for a recording, choose an installed batch speech model, and add the finished transcript to your active note. Language, timestamps, speaker labels, and paragraph formatting can be set for each job without changing your dictation settings. Media stays on your computer.
- **Bring YouTube captions into your notes.** Paste a video link to import its available creator or automatic captions, with a language choice and optional links back to the video. Caption import needs no video download or speech model.
- **Use AI presets on complete transcripts.** Choose a preset before starting either workflow to summarize, outline, or transform the transcript with your configured local or remote AI provider. The raw transcript remains available if AI processing fails.

## Improvements

- **Clearer transcription dialogs.** File and YouTube commands have focused dialogs, grouped settings with consistent spacing, progress and cancellation, and an explicit recovery path when partial file transcription is available.
- **Install the media decoder where it is needed.** The file dialog offers decoder setup when it is missing, keeps the chosen file in place, and waits for you to start transcription. Advanced settings now reflects whether the decoder is installed and offers a reinstall action. File model choices also follow each model's language support, so English-only models are hidden when Auto detect is selected.

## Fixes

- **Finish long file transcriptions reliably.** File audio now stays within the local speech engine's processing capacity, avoiding the queue overload that could stop a recording early. Live dictation keeps its existing behavior.

## Compatibility

- **One-time media decoder setup for files.** File transcription uses a separately installed, verified media decoder to extract audio from common audio and video formats. Install it from the file dialog or **Settings → Speech Kit → Advanced**. Speech Kit also offers to install the updated native speech engine for this release.

## Known Limitations

- **YouTube uses existing captions only.** Videos without usable captions, or with captions unavailable in the chosen language, leave the note unchanged. This command does not download audio or run local speech recognition.
