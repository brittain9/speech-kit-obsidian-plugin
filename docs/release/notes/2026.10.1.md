## Highlights

- **Speech Kit now runs on ARM64 Windows and Linux.** Windows on ARM laptops (Snapdragon 8cx and newer, including Snapdragon X) and ARM64 Linux machines (Raspberry Pi 5, Graviton, Ampere, Jetson Orin) get a native speech engine. Dictation, every speech engine, translation, read aloud, system audio, and audio/video file transcription all work. The setup wizard picks the ARM64 build automatically.

## Performance

- **Tuned for newer ARM chips.** The ARM64 engine targets ARMv8.2 with the int8 dot-product extension, which runs local Whisper models much faster and uses less battery than a baseline ARM build.

## Compatibility

- **ARM64 requirements.** Linux ARM64 needs an ARMv8.2 CPU and a 64-bit OS with glibc 2.39 or newer, such as Raspberry Pi OS Trixie, Debian 13, or Ubuntu 24.04 (Bookworm is too old). The setup wizard tells Raspberry Pi 4 and other older ARM boards that they are not supported. NVIDIA CUDA acceleration remains x86-64 only.
- **Fresh native engine archives.** Speech Kit offers a one-click reinstall of the speech engine after updating.
