# Run Qwen ASR through the existing native llama.cpp runtime

Qwen3-ASR adds an audio encoder and a causal text decoder; the currently pinned `llama-cpp-2` 0.1.160 and `llama-cpp-sys-2` 0.1.161 already includes Qwen audio support and safe Rust MTMD bindings. Enable its existing MTMD feature behind a separate Qwen ASR family instead of shipping Python/vLLM, adding a Mac-only MLX runtime, or maintaining a custom ONNX export pipeline. Per ADR 0005, all llama.cpp inference lives in a separate version-matched `local-dictation-asr-helper`; linking it into the main Whisper sidecar would recreate the GGML symbol collision. The helper compiles its small shared modules directly and never imports the main sidecar library. Keep the existing registry, managed artifact installer, native VAD, and worker lifecycle as the integration boundary. The family must load and validate a matched text-model/audio-projector pair before advertising readiness.

Start with bounded batch inference: at most 35 seconds per engine request, with existing native VAD splitting longer sessions at 30 seconds. Reset decoder state between requests; cap generated tokens and reject truncated output rather than silently accepting it. Validate supported language conditioning, parse model control tokens into a detected language and plain transcript, and advertise no word timestamps without a separately validated aligner. Existing model defaults remain unchanged.

The official Qwen streaming API retains audio/text state but re-encodes accumulated audio with a rolled-back text prefix for each chunk. It is not proof of a persistent streaming encoder cache. A later bounded partial-transcription prototype may follow that behavior, but must measure paced chunk latency, final reconciliation, cancellation/reset, and the VAD stop boundary before becoming a live-dictation option. Describe this as progressive re-decoding rather than claiming cached stateful streaming.

Managed catalog adoption requires actual short and natural long fixture quality, language/automatic detection, silence, reset/cancellation, pair integrity/probe, and a real installer path. Add the 1.7B variant only after the smaller checkpoint proves the runtime and the same adapter earns the added model choice. The initial footprint budget is 4 GB new transfers and 10 GB disk; no paid resources, training, or release changes.

The native adapter supervises bounded framed pipes to its exact sibling helper, with actionable missing/version-mismatch errors and deterministic child cleanup. Keep its protocol separate from translation so dictation and an existing translation can retain independent lifetimes. A default cancellable inference entrypoint delegates to existing adapters unchanged; Qwen observes the worker cancellation signal while waiting for helper load/decode, terminates and reaps the isolated child, and starts a fresh helper for retry. Do not add a generic process framework for this slice.
