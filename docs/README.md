# Documentation

## Use Speech Kit

- [Transcribe files and YouTube captions](guides/media-transcription.md), including AI provider setup and note safety.
- [Review AI presets](guides/ai-preset-prompts.md) and their default prompts.
- [Set up Linux](guides/linux-support.md) or [enable CUDA for Whisper](guides/cuda-setup.md).
- [Install and test Moonshine](guides/moonshine-live-testing.md), including reinstalling a model.

Open **Settings → Speech Kit** to manage models, capture, output, reading, translation, and optional AI tools. See the [README](../README.md) for supported platforms and getting started.
